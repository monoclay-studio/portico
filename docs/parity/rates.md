# Parity: rates

Status: v1 · 2026-11-07 · Cluster `front` · Spec `docs/specs/rates.md` (RAT) · Implementation: `modules/rates`
(status and tests updated by the rates engineer after the steward review round, 2026-11-07). Test paths are relative
to `modules/rates/` unless they start with `apps/`. "Partial" notes say what keeps a row below `tested`.

**Baseline.** OPERA Cloud 26.3 *Rate Management* administration (rate classes/categories/seasons, rate codes,
base/dynamic/BAR rates, occupant thresholds, child age buckets, posting rhythms, tiered rates, rate protection and
ownership, promotions, hurdle rates, yield, rate strategies, property calendar, package codes and groups, generates)
plus *Booking Rules and Schedules* (cancel penalties, deposit rules, reservation types and their schedules) and
OPERA Cloud Distribution *Pricing*. Modern rows from the Mews Connector API (rates, restrictions, taxations,
revenue-management use case), Apaleo rate-plan/settings APIs, Cloudbeds and SiteMinder. Links opened (or found by
web search where the vendor blocks direct fetch) on 2026-11-07. Capability column uses Portico terms (rate plan,
price, restriction, inclusion, allowance, package, meal plan, tax & fee rule, agreed terms).
