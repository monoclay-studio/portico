# Parity: groups (blocks, allotments, sales & events, function space)

Status: v1 · 2026-11-07 · Cluster `front` · Spec `docs/specs/groups.md` (GRP, wave 2) · Code on `main`: none, so no
row is `built`/`tested`.

**Baseline.** OPERA Cloud 26.3 user guide: *Bookings → Blocks* (master/sub blocks, allocations, opportunities,
elastic/sell limits/shoulder dates, tour series, rooming lists, group rooms control, shift, cut-off, status,
wash schedule, access exclusion, restrictions, sell messages, packages, block exchange, change logs), *Events*
(function diary, alternate space, sub-events, waitlist, resources, menus, revenue, posting), *Booking
Administration* (block management codes, status flow, cut-off schedules, catering codes, resource management,
sales goals) and *Inventory Administration → Function Space Management*; *Blocks and Groups Reports*. Modern rows
from the Apaleo groups/blocks API and guide, the Mews availability-block API, Cloudbeds Groups/allotment blocks
and Stayntouch groups. Links opened (or found by web search where the vendor blocks direct fetch) on 2026-11-07.
Capability column uses Portico terms (group, block, allotment, rooming list, pickup, cut-off, event, event order).

**Priority note.** Tour-operator/DMC allotments are a core resort commercial model in the Maldives (RAT §11,
GRP §11), so allotment rows are P0; general group/MICE rows are P1.
